## Three Key Lessons I Learned About Clean Code:

- Use **descriptive names for functions and variables** to make code more understandable.
- **Avoid repetition** by reusing logic through functions and classes.
- **Follow consistent formatting and style guidelines** to make code easier to read and maintain.
